# P11 — Working memory and knowledge retrieval are different subsystems.

Part of [[guiding-principles-invariants|Guiding Principles]].

The sandbox filesystem/object store is agent *working memory*; RAG/GraphRAG is *enterprise knowledge retrieval*. They are never conflated or merged into one abstraction.
