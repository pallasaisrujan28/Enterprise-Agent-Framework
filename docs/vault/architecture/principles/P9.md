# P9 — Loop first, graph last.

Part of [[guiding-principles-invariants|Guiding Principles]].

The default unit of work is one agentic loop with a goal and a quality bar. A declarative graph is added only when the work forces it (distinct specialties, per-step model/toolset differences, fan-out/fan-in, auditable routing, failure isolation, read-only review). Many thin nodes that could collapse into one loop is an anti-pattern.
